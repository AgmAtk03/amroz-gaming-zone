# Amroz Gaming Zone

Marketing demo site for **Amroz Gaming Zone** — a Kathmandu Ward 32 PlayStation club and electronics hangout.

## Live demo

- **Public (no login):** https://agmatk03.github.io/amroz-gaming-zone/
- **Vercel production:** https://amroz-ward32-dristi-astra.vercel.app/ — Dristi Astra Hobby team; if this URL shows a Vercel login, turn off **Deployment Protection → Vercel Authentication** on the `amroz-ward32` project.

## Stack

- Next.js App Router
- Tailwind CSS
- Vercel + GitHub Pages

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Hours, phone, membership rates, reviews, gallery tiles, and social URLs are **demo placeholders** unless marked otherwise.
